# Phase 0: 파라미터 설정

## 🔧 개요

시스템을 시작하기 전에 필요한 모든 좌표와 설정값을 정의합니다.  
이 단계에서는 로봇이 각 위치에 정확히 도달하도록 좌표를 설정하고, 카메라와 센서를 초기화합니다.

---

## 📍 주요 파라미터

### 1. **집기 위치 (Pick Position)**
| 파라미터 | 설명 | 현재값 |
|---------|------|-------|
| `집기_x__좌표` | X축 좌표 (고정) | 277 |
| `집기_y_좌표__목록` | Y축 좌표 목록 (3개 위치) | [-40, 0, 40] |
| `집기_z__좌표` | Z축 깊이 (물체 흡입 깊이) | -60 |
| `집기__높이` | 흡입 높이 | 22 |

### 2. **컨베이어 위치 (Conveyor Position)**
| 파라미터 | 설명 | 현재값 |
|---------|------|-------|
| `컨베이어__대기` | 컨베이어 대기 위치 | (230, 250, 80) |
| `컨베이어__놓기` | 컨베이어에 물체를 놓는 위치 | (230, 260, 22) |

### 3. **스캔 위치 (Scan Position)**
| 파라미터 | 설명 | 현재값 |
|---------|------|-------|
| `스캔__위치` | 스캔 카메라 위치 | (0, 230, 100) |

### 4. **분류 위치 (Classification Position)**
| 파라미터 | 설명 | 현재값 |
|---------|------|-------|
| `분류_x__좌표` | X축 좌표 (고정) | -270 |
| `분류_y_좌표__목록` | Y축 좌표 목록 (3개 위치) | [80, 5, -70] |
| `분류_z__좌표` | Z축 깊이 | 0 |

### 5. **홈 위치 (Home Position)**
| 파라미터 | 설명 | 현재값 |
|---------|------|-------|
| `HOME_X__좌표` | 홈 X축 좌표 | 280 |
| `HOME_Y__좌표` | 홈 Y축 좌표 | 0 |

### 6. **기본 높이 (Default Height)**
| 파라미터 | 설명 | 현재값 |
|---------|------|-------|
| `기본_Z__좌표` | 기본 Z축 높이 (안전 높이) | 100 |

## 🖥️ 파라미터 설정 코드

```python
# 집기 위치 설정
집기_y_좌표__목록 = [-40, 0, 40]  # 3개의 물체 위치
집기_x__좌표 = 277
집기_z__좌표 = -60
집기__높이 = 22

# 컨베이어 위치 설정
컨베이어__대기 = (230, 250, 80)
컨베이어__놓기 = (230, 260, 집기__높이)

# 스캔 위치 설정
스캔__위치 = (0, 230, 100)

# 분류 위치 설정
분류_y_좌표__목록 = [80, 5, -70]  # 3개의 분류 위치
분류_x__좌표 = -270
분류_z__좌표 = 0

# 홈 위치 설정
HOME_X__좌표 = 280
HOME_Y__좌표 = 0
HOME = (HOME_X__좌표, HOME_Y__좌표, 0)

# 기본 안전 높이
기본_Z__좌표 = 100
```

## 📝 파라미터 조정 가이드

각 좌표는 다음과 같이 조정합니다:

- **X, Y 좌표**: 로봇 팔의 수평 이동 위치
- **Z 좌표**: 로봇 팔의 높이 (음수 = 더 낮음)
- **목록 값**: 여러 물체가 있을 때 순서대로 처리할 위치들

> **💡 팁**: 처음 설정할 때는 일반적인 값을 사용하고, 실제 작동 후 미세 조정합니다.
