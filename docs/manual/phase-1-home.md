# Phase 1: 홈 (Home Position)

## 🏠 개요

로봇을 **안전한 대기 위치(홈)**로 이동합니다.  
모든 작업 사이클은 홈 위치에서 시작되며, 로봇이 다른 장애물과 충돌하지 않도록 하는 안전 메커니즘입니다.

---

## 🎯 목표

- 로봇을 홈 위치로 이동
- 다음 Phase로 진행할 준비 완료

---

## 🔄 동작 과정

### 1단계: 로봇 이동
로봇이 현재 위치에서 홈 위치로 이동합니다.

```
[현재 위치] → 🤖 → [홈 위치]
```

---

## 🖥️ Phase 1 코드

```python
def phase_1():
    # 로봇을 홈 위치로 이동
    robot.moveG0(HOME_X__좌표, HOME_Y__좌표, 기본_Z__좌표)
    time.sleep(0.5)  # 안정화 대기

# 메인 루프에서 실행
robot.moveG0(HOME)
```

### 코드 설명

| 블록 | 설명 |
|------|------|
| `robot.moveG0(HOME_X, HOME_Y, Z)` | 로봇 팔을 지정된 좌표로 빠르게 이동 |
| `time.sleep(0.5)` | 이동 후 0.5초 안정화 시간 |

---

## 📊 파라미터 확인

| 파라미터 | 값 | 의미 |
|---------|-----|------|
| `HOME_X__좌표` | 280 | X축 홈 위치 |
| `HOME_Y__좌표` | 0 | Y축 홈 위치 |
| `기본_Z__좌표` | 100 | 안전한 Z축 높이 |
