# Phase 2: 컨베이어 이동 (Conveyor Movement)

## 🎛️ 개요

로봇이 **지정된 위치에서 물체를 집어** 컨베이어 위에 놓습니다.  
이 단계에서는 흡입 기능(suction)을 사용하여 물체를 들고, 컨베이어로 이동하여 안전하게 놓습니다.

---

## 🎯 목표

1. 집기 위치로 이동
2. 물체 흡입 (suction on)
3. 컨베이어로 이동
4. 컨베이어 위에 물체 놓기

---

## 🔄 동작 과정

### 1단계: 집기 위치로 이동 (상단)
로봇이 안전 높이에서 집기 위치로 이동합니다.

```
[홈] 
  ↓ (안전 높이)
[집기 위치 상단]
```

### 2단계: 집기 위치로 이동 (하단)
로봇이 내려와서 물체를 집습니다.

```
[집기 위치 상단]
  ↓ (집기 높이까지 내려감)
[물체 위치] ← 흡입 시작 ✓
```

### 3단계: 물체 흡입 (1초)
흡입 기능을 켜서 물체를 집습니다.

```
🤖 [흡입 중...] 1초 대기
```

### 4단계: 컨베이어로 이동
로봇이 물체를 들고 컨베이어로 이동합니다.

```
[집기 위치] 
  ↓
[안전 높이]
  ↓
[컨베이어 대기 위치]
  ↓
[컨베이어 놓기 위치]
```

### 5단계: 물체 놓기
컨베이어 위에 물체를 놓고 흡입을 해제합니다.

```
🤖 [흡입 해제] ← 물체 떨어짐 ✓
```

## 🖥️ Phase 2 코드

```python
def phase_2():
    global 집기_y_좌표__목록, 집기_Y__좌표, i
    
    # 현재 처리할 집기 Y 좌표 선택
    집기_Y__좌표 = 집기_y_좌표__목록[int(i)]
    
    # Step 1: 집기 위치 상단으로 이동 (안전 높이)
    robot.moveG0(집기_x__좌표, 집기_Y__좌표, 기본_Z__좌표)
    
    # Step 2: 집기 위치까지 내려가기
    robot.moveG0(집기_x__좌표, 집기_Y__좌표, 집기_z__좌표)
    
    # Step 3: 물체 흡입 시작
    robot.suctionOn()
    time.sleep(1)  # 1초 흡입
    
    # Step 4: 안전 높이로 올리기
    robot.moveG0(집기_x__좌표, 집기_Y__좌표, 기본_Z__좌표)
    
    # Step 5: 컨베이어 대기 위치로 이동
    robot.moveG0(컨베이어__대기)
    
    # Step 6: 컨베이어에 물체 놓기
    robot.moveG0(컨베이어__놓기)
    
    # Step 7: 흡입 해제
    robot.suctionOff()
    time.sleep(2)  # 안정화 대기
    
    # Step 8: 컨베이어 대기 위치로 돌아가기
    robot.moveG0(컨베이어__대기)
    
    # Step 9: 컨베이어 벨트 동작 (물체 이동)
    robot.sendCommand("M204 R5\n")     # 가속도 설정
    robot.sendCommand("M203 E30\n")    # 최대 속도 설정
    robot.sendCommand("G91\n")         # 상대 좌표 모드
    robot.sendCommand("G1 E43\n")      # 43mm 이동
    robot.sendCommand("G90\n")         # 절대 좌표 모드
```

### 코드 블록별 설명

| 블록 | 코드 | 설명 |
|------|------|------|
| 1️⃣ | `moveG0(x, y, z)` | 로봇을 지정 좌표로 이동 |
| 2️⃣ | `suctionOn()` | 흡입 시작 |
| 3️⃣ | `time.sleep(1)` | 1초 대기 |
| 4️⃣ | `suctionOff()` | 흡입 해제 |
| 5️⃣ | `sendCommand()` | 컨베이어 벨트 제어 |

## 📊 주요 파라미터

| 파라미터 | 현재값 | 설명 |
|---------|-------|------|
| `집기_x__좌표` | 277 | 집기 X축 위치 |
| `집기_y_좌표__목록[i]` | [-40, 0, 40] | 3개 물체 Y축 위치 |
| `집기_z__좌표` | -60 | 물체 집는 깊이 |
| `기본_Z__좌표` | 100 | 안전 높이 |
| `컨베이어__대기` | (230, 250, 80) | 컨베이어 대기 좌표 |
| `컨베이어__놓기` | (230, 260, 22) | 물체 놓는 위치 |

---

## ⚙️ 파라미터 조정 시 주의사항

- **집기_z__좌표**: 더 내려가려면 음수를 크게 (예: -60 → -70)
- **흡입 시간**: 가벼운 물체는 0.5초, 무거운 물체는 1.5초 증가
- **컨베이어 속도**: E43 값을 변경하여 조정
