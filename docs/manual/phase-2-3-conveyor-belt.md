# 컨베이어 벨트 제어 (Conveyor Belt Control)

## 🎛️ 개요

물체를 컨베이어에 놓은 후, 벨트를 회전시켜 물체를 스캔 위치로 이동시킵니다.

---

## 🔄 동작 과정

### 1단계: 흡입 해제

```python
robot.suctionOff()  # 흡입 중지
time.sleep(2)       # 안정화 대기
```

**결과**: 물체가 컨베이어 위에 떨어짐

---

### 2단계: 로봇 이동

```python
robot.moveG0(컨베이어__대기)  # (230, 250, 80)
```

**결과**: 로봇이 컨베이어에서 물러남

---

### 3단계: 컨베이어 벨트 회전

```python
# 속도 설정
robot.sendCommand("M204 R5\n")      # 가속도 설정
robot.sendCommand("M203 E30\n")     # 최대 속도

# 상대 좌표 모드
robot.sendCommand("G91\n")

# 43mm 이동
robot.sendCommand("G1 E43\n")

# 절대 좌표 모드 복구
robot.sendCommand("G90\n")
```

**결과**: 컨베이어 벨트가 물체를 43mm 이동

---

## ⚙️ 파라미터 설정

| 명령 | 값 | 설명 | 조정 |
|------|-----|------|------|
| `M204 R5` | 5 | 가속도 | 빠르게: 3 / 천천히: 10 |
| `M203 E30` | 30 | 최대 속도 | 빠르게: 50 / 천천히: 15 |
| `G1 E43` | 43 | 이동 거리(mm) | 더 이동: 60 / 덜 이동: 30 |

---

## 💡 팁

**물체가 스캔 위치에 정확히 도달하지 않을 때:**
- E43 값 조정 (현재 43mm → 증가 또는 감소)
- 속도 E30 값 조정 (너무 빠르면 물체 이탈)

**예시**: 더 많이 이동시키려면
```python
robot.sendCommand("G1 E50\n")  # 43mm → 50mm
```
