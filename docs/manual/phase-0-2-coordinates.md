# 좌표 설명

## 🔢 좌표 시스템

로봇은 3D 공간에서 움직입니다:
- **X축**: 좌우 이동
- **Y축**: 앞뒤 이동  
- **Z축**: 위아래 이동 (높이)

```
        Z축 (높이)
          ↑
          |
Y축 (앞뒤) | 집기 위치 (277, -40~40, -60)
↗        |     
         +------→ X축 (좌우)
```

---

## 📊 각 위치별 좌표

| 위치 | X | Y | Z | 설명 |
|------|----|----|----|----|
| 홈 (HOME) | 280 | 0 | 0 | 대기 위치 |
| 집기 | 277 | -40, 0, 40 | -60 | 물체 집기 위치 |
| 컨베이어 | 230 | 250 | 80 | 컨베이어 대기 |
| 스캔 | 0 | 230 | 100 | 카메라 인식 |
| 분류 | -270 | 80, 5, -70 | 0 | 물체 분류 |

---

## 💡 좌표 조정 팁

1. **Y축 좌표 추가**: 집기 위치가 4개 이상 필요하면
   ```python
   집기_y_좌표__목록 = [-40, 0, 40, 80]  # 4개로 확장
   ```

2. **Z축 (높이) 조정**: 물체가 더 높으면
   ```python
   집기_z__좌표 = -50  # 덜 내려감
   ```

3. **안전 높이**: 로봇이 충돌하지 않도록
   ```python
   기본_Z__좌표 = 100  # 이 높이 이상에서만 이동
   ```
