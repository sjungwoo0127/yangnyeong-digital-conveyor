# 물체 분류 규칙 (Classification Rules)

## 🎯 개요

AI가 인식한 물체의 종류(`tag_id`)에 따라 적절한 분류 위치로 옮깁니다.

---

## 📍 분류 위치 설정

### 현재 설정

```python
분류_x__좌표 = -270              # X축 위치 (고정)
분류_y_좌표__목록 = [80, 5, -70]   # Y축 위치 (3개)
분류_z__좌표 = 0                # Z축 높이 (물체 놓기)
```

---

## 🔄 분류 규칙

### 규칙: tag_id → 분류 위치

```python
tag_id = 1 → 분류_y = 분류_y_좌표__목록[0] = 80
tag_id = 2 → 분류_y = 분류_y_좌표__목록[1] = 5
tag_id = 3 → 분류_y = 분류_y_좌표__목록[2] = -70
```

---

## 🖥️ 분류 코드

```python
def phase_4():
    while True:
        # 물체 감지
        result = _stable_check(1, 10, 3)
        
        if result != None:
            pixel_x, pixel_y, tag_id = result  # tag_id 추출
            
            # 로봇 좌표로 변환
            target_x, target_y = pixel_to_suction_movement(pixel_x, pixel_y)
            
            # 물체 집기
            robot.moveG0(target_x, target_y, 기본_Z__좌표)
            robot.suctionOn()
            time.sleep(1)
            
            # 분류 위치 선택 ← 핵심
            분류_y = 분류_y_좌표__목록[tag_id - 1]  # tag_id - 1 사용
            
            # 분류 위치로 이동
            robot.moveG0(분류_X__좌표, 분류_y, 기본_Z__좌표)
            
            # 물체 놓기
            robot.suctionOff()
            
            # 홈으로 돌아가기
            robot.moveG0(HOME_X__좌표, HOME_Y__좌표, 기본_Z__좌표)
            break
```

## ⚙️ 분류 추가

**4개 이상의 물체를 분류해야 하면:**

```python
# 분류 위치 4개 추가
분류_y_좌표__목록 = [80, 5, -70, 50]  # 4개

# 분류 공간도 4개 필요
# tag_id = 4 → Y = 50 위치로 이동
```

## 💡 분류 문제 해결

| 문제 | 원인 | 해결 |
|------|------|------|
| 물체가 잘못된 위치로 | AI가 잘못 인식 | 조명 또는 카메라 각도 확인 |
| 분류 위치가 비어있음 | tag_id가 너무 큼 | `분류_y_좌표__목록` 확인 |
| 물체가 분류 위치에 정확히 안 떨어짐 | 로봇 좌표 오류 | Phase 4-2 좌표 변환 확인 |
