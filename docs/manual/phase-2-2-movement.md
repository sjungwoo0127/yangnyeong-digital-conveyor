# 컨베이어 이동 (Movement to Conveyor)

## 🚀 개요

물체를 든 상태로 컨베이어 위치로 이동합니다.

---

## 🔄 이동 경로

### 1단계: 안전 높이 확보

```python
robot.moveG0(집기_x__좌표, 집기_Y, 기본_Z__좌표)
```

**이유**: 다른 장애물과의 충돌 방지

---

### 2단계: 컨베이어로 이동

```python
robot.moveG0(컨베이어__대기)  # (230, 250, 80)
```

**결과**: 로봇이 컨베이어 대기 위치로 이동

---

### 3단계: 물체 놓기 위치로 이동

```python
robot.moveG0(컨베이어__놓기)  # (230, 260, 22)
```

**결과**: 로봇이 물체를 정확히 컨베이어 위에 놓을 위치로 이동

---

## 📍 위치 설명

| 위치 | 좌표 | 의미 |
|------|------|------|
| 컨베이어__대기 | (230, 250, 80) | 대기 위치 (안전 높이) |
| 컨베이어__놓기 | (230, 260, 22) | 물체 놓기 위치 |

---

## ⚙️ 이동 시간 조정

만약 로봇이 컨베이어에 도달하는 데 너무 오래 걸린다면:

```python
# 이동 후 안정화 시간 조정
time.sleep(0.5)  # 기본값: 필요 시 조정
```
