# Phase 3: 스캔 준비

## 블록 다이어그램

> 블록 이미지 공간 - 사용자가 나중에 삽입

***

## 개요

로봇을 스캔 위치로 옮기고, 카메라가 물체를 잘 인식하도록 환경에 맞춰 설정하는 단계입니다. 이 Phase는 "이동 블록 + 카메라 준비 블록" 두 개로 구성됩니다.

***

## 블록별 설명

### 블록 1️⃣: 스캔 위치로 이동 블록

**기능**: 로봇을 카메라가 설치된 스캔 위치로 이동

* 안전 높이로 바로 이동

**파라미터**:

* X: 0
* Y: 230
* Z: 100 (안전 높이)

**주의사항**:

* 물체가 벨트 위에서 완전히 멈춘 후에 이동해야 함

***

### 블록 2️⃣: 카메라 준비 블록

**기능**: 환경 밝기에 맞춰 카메라를 인식 모드로 설정

* 안에 "레벨 선택" 파라미터를 하나 넣음

**파라미터**:

* 카메라 레벨: 2 (보통 밝기, 기본값)
* 레벨 1: 어두운 실내
* 레벨 2: 보통 실내 (기본)
* 레벨 3: 밝은 실내
* 레벨 4: 실외/매우 밝음

**주의사항**:

* 카메라 준비에는 약 1.1초가 걸림 (자동 조정 + 안정화)
* 이 블록이 끝나기 전에는 Phase 4로 넘어가지 말 것
