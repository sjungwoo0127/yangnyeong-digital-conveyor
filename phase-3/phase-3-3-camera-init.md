# 카메라 초기화 과정 (Camera Initialization)

## 블록 다이어그램

![카메라 초기화 블록](../assets/phase-3-3-init.png)

> 블록 이미지 공간 - 사용자가 나중에 삽입

---

## 개요

카메라를 "물체 인식이 가장 잘 되는 상태"로 만드는 6단계 블록 시퀀스입니다.
이 전체 과정은 약 1.1초가 걸립니다.

---

## 블록별 설명

### 블록 1️⃣: 레벨별 설정값 선택 블록

**기능**: 선택한 레벨에 해당하는 노출 스케일과 최대 게인을 변수에 저장

**파라미터 (레벨 2 예시)**:
- 노출 스케일: 0.70
- 최대 게인: 4

---

### 블록 2️⃣: 카메라 일시 중지 블록

**기능**: 자동 설정을 적용하기 위해 카메라를 잠시 멈춤

**파라미터**: 없음

---

### 블록 3️⃣: 자동 설정 활성화 블록 묶음

**기능**: 자동 게인/자동 화이트 밸런스/자동 노출을 모두 ON
- 그리고 최대 게인 상한 적용

**파라미터**:
- 자동 게인: ON
- 자동 화이트 밸런스: ON
- 자동 노출: ON
- 최대 게인: 4 (예시)

---

### 블록 4️⃣: 카메라 시작 블록

**기능**: 설정이 적용된 상태로 카메라를 다시 켬

**파라미터**: 없음

---

### 블록 5️⃣: 초기 안정화 대기 블록

**기능**: 자동 설정이 안정화될 때까지 프레임을 잠시 버림

**파라미터**:
- 대기 시간: 800 ms (약 8프레임)

---

### 블록 6️⃣: 현재 노출값 읽기 + 스케일 적용 블록

**기능**: 지금 카메라가 찍고 있는 노출값을 읽고, 노출 스케일을 곱해 "고정 노출값"을 계산

**파라미터**:
- 입력: 현재 자동 노출값
- 계산: 현재 값 × 노출 스케일 (예: 0.70)
- 결과: 고정 노출값

---

### 블록 7️⃣: 최종 설정 적용 블록 묶음

**기능**: 카메라를 다시 잠시 멈추고, 계산한 고정 노출값과 세부 영상 설정을 최종 반영

**파라미터**:
- 자동 노출: OFF (고정 노출 사용)
- 자동 게인: ON
- 최대 게인: 4
- 자동 화이트 밸런스: OFF
- 밝기: 0 (기본)
- 명도차: 0 (기본)
- 채도: 0 (기본)

---

### 블록 8️⃣: 카메라 재시작 블록

**기능**: 최종 설정으로 카메라 재가동

**파라미터**: 없음

---

### 블록 9️⃣: 최종 안정화 대기 블록

**기능**: 최종 설정이 자리 잡도록 짧게 대기

**파라미터**:
- 대기 시간: 300 ms (약 3프레임)

---

## 초기화 완료 체크리스트

- [ ] 카메라 정상 작동
- [ ] 자동 설정 1차 적용 완료
- [ ] 고정 노출값 계산 및 적용
- [ ] 800ms + 300ms 대기 완료
- [ ] 물체 인식 가능 상태

---

## 초기화 시간

- **전체 시간**: 약 1.1초 (800ms + 300ms)
- **목표**: 물체가 정확히 인식될 수 있도록 카메라 최적화
