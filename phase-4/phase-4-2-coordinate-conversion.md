# 좌표 변환

## 블록 다이어그램

> 블록 이미지 공간 - 사용자가 나중에 삽입

***

## 개요

카메라가 본 "픽셀 좌표"를 로봇 팔이 움직일 수 있는 "공간 좌표(mm)"로 바꾸는 블록입니다. 복잡한 계산은 변환 블록 안에서 자동으로 처리됩니다.

***

## 좌표 개념

**카메라 이미지** (픽셀 단위)

```
┌─────────────┐
│     ●       │ (pixel_x, pixel_y)
│             │ 범위: 0~320, 0~240
└─────────────┘
```

**로봇 공간** (mm 단위)

* 로봇 팔 흡입기가 실제로 도달할 수 있는 (X, Y, Z) 위치

***

## 블록별 설명

### 블록 1️⃣: 픽셀 → 로봇 좌표 변환 블록

**기능**: 픽셀 좌표와 물체 높이를 입력받아 로봇이 이동할 (X, Y) 좌표를 계산

* 내부에서 4단계 계산을 자동으로 수행

**파라미터**:

* 입력 픽셀 X
* 입력 픽셀 Y
* 물체 높이(집기 높이): 22

**출력**:

* 로봇 X (mm)
* 로봇 Y (mm)

**내부 계산 단계**:

1. 픽셀을 mm 단위로 변환
2. 카메라 높이에 따른 보정
3. 로봇 각도 보정 (삼각함수 적용)
4. 최종 로봇 좌표 출력

***

### 블록 2️⃣: 카메라 설정 상수 블록

**기능**: 변환에 필요한 고정값들을 한꺼번에 정의

* 블록 1️⃣이 내부적으로 사용

**파라미터**:

| 파라미터   | 값       | 설명        |
| ------ | ------- | --------- |
| 카메라 높이 | 93.7 mm | 카메라 설치 높이 |
| 흡입기 높이 | 40 mm   | 흡입기 기준 높이 |
| X 오프셋  | -28 mm  | X축 보정     |
| Y 오프셋  | -16 mm  | Y축 보정     |

***

## 변환 확인

물체가 정확히 집히지 않는다면:

1. 카메라 각도 확인
2. Phase 3 카메라 설정 재점검
3. X/Y 오프셋 값 미세 조정

***

## 주의사항

* 이 블록은 "이미 Phase 3에서 카메라가 제대로 준비된 상태" 를 전제로 함
* 카메라 위치가 움직였다면 상수값(카메라 높이, 오프셋) 도 다시 측정해야 함
