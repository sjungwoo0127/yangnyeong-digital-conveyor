# 안전 수칙

## ⚠️ 시스템 운영 전 필수 확인사항

컨베이어 로봇 시스템은 기계적으로 작동하므로 **안전 수칙을 반드시 숙지**한 뒤 운영해야 합니다.

---

## 🚨 작동 중 주의사항

### 1. 로봇 팔 동작 범위 내 접근 금지
- 로봇 팔이 움직이는 범위 안에 손이나 물체를 두지 마세요.
- 특히 홈 복귀 시 예상치 못한 방향으로 이동할 수 있습니다.

### 2. 컨베이어 벨트 주의
- 동작 중인 컨베이어에 손이나 옷, 머리카락이 말려 들어가지 않도록 주의하세요.
- 반지, 시계, 긴 소매 등은 탈착 후 작업하세요.

### 3. 그리퍼(흡착) 주의
- 흡착 중 물체가 떨어질 수 있으므로 낙하 방향에 사람이 있지 않도록 하세요.
- 흡착력이 약해지면 즉시 시스템을 정지하고 점검하세요.

---

## 🛑 비상 정지 절차

1. **비상 정지 버튼(E-Stop)**을 누른다.
2. 전원을 차단한다.
3. 로봇 팔이 완전히 멈춘 것을 확인한다.
4. 이상이 있을 경우 지도 교사에게 보고한다.

---

## 🧰 사용 전 점검 체크리스트

- [ ] 전원 케이블이 정상적으로 연결되어 있는가?
- [ ] 그리퍼의 공기 호스가 꺾이지 않았는가?
- [ ] 카메라 렌즈에 먼지나 오염이 없는가?
- [ ] 컨베이어 벨트에 이물질이 없는가?
- [ ] 로봇 팔 작동 범위 내 장애물이 없는가?
- [ ] LCD 화면이 정상적으로 켜지는가?

---

## 📢 사고 발생 시 대처

- 즉시 비상 정지 버튼을 누른다.
- 전원을 차단한다.
- 절대로 직접 수리하지 말고 지도 교사에게 알린다.
