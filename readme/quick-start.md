# 빠른 시작 가이드

이 가이드는 처음 시스템을 사용하는 학생을 위해 **가장 빠르게 동작 확인**을 할 수 있도록 작성되었습니다.

---

## ⏱️ 1분 요약

1. 전원을 켠다.
2. 제어 프로그램을 실행한다.
3. Phase 0 → Phase 4가 자동으로 순차 진행된다.
4. LCD와 로봇의 동작을 관찰한다.

---

## 🔌 Step 1. 전원 켜기

1. 메인 전원 스위치를 ON 상태로 놓는다.
2. 컴프레서(공기 압축기)가 정상 작동하는지 확인한다.
3. LCD 화면에 부팅 메시지가 뜨는지 확인한다.

---

## 💻 Step 2. 제어 프로그램 실행

```python
import robot, cam, sensor, lcd

# 기본 초기화
lcd.init()
cam.ai_init(5)

# 전체 시퀀스 실행
run_all_phases()
```

> 📝 `run_all_phases()` 함수는 Phase 0부터 Phase 4까지 자동 실행합니다.

---

## 👀 Step 3. 동작 관찰

| 확인 포인트 | 기대 동작 |
|-------------|-----------|
| **로봇 팔** | 홈 → 집기 → 컨베이어 → 분류 위치 순 이동 |
| **컨베이어** | 물체를 스캔 위치까지 이동 |
| **카메라** | AI가 물체를 인식하고 결과 출력 |
| **LCD** | 각 Phase 진행 상황 표시 |

---

## ❓ 문제가 발생했다면

- 로봇이 움직이지 않음 → [Phase 0: 파라미터 설정](../phase-0/README.md) 확인
- 물체를 집지 못함 → [Phase 2: 그리퍼](../phase-2/phase-2-1-gripper.md) 확인
- 카메라가 인식 못 함 → [Phase 3: 스캔 준비](../phase-3/README.md) 확인
- 분류가 잘못됨 → [Phase 4: 분류 규칙](../phase-4/phase-4-3-classification-rules.md) 확인
