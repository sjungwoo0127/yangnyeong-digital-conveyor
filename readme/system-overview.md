# 시스템 개요

## 🎯 시스템 목적

양녕 디지털고 컨베이어 시스템은 로봇 팔과 컨베이어, AI 카메라를 결합하여 **물체를 자동으로 집고, 이동시키고, 인식하여 분류**하는 교육 및 실습용 장비입니다.

---

## 🧩 주요 구성 요소

| 구성 요소 | 설명 |
|-----------|------|
| **로봇 팔** | 지정된 좌표로 이동하여 물체를 집고 놓음 |
| **그리퍼(Gripper)** | 공기 흡착 방식으로 물체를 집음 |
| **컨베이어 벨트** | 집은 물체를 스캔 위치로 이송 |
| **AI 카메라** | 물체 종류를 이미지로 인식 |
| **LCD 디스플레이** | 상태 및 인식 결과 출력 |
| **제어 보드** | 전체 동작을 Python 코드로 제어 |

---

## 🔄 동작 흐름

```
[Phase 0] 파라미터 설정
      ↓
[Phase 1] 홈 위치로 이동
      ↓
[Phase 2] 물체 집기 → 컨베이어로 이동
      ↓
[Phase 3] 카메라로 스캔
      ↓
[Phase 4] 인식 결과에 따라 분류 위치로 이동
```

---

## 💡 시스템 특징

- **모듈화된 단계 구조**: 각 Phase가 독립적으로 관리되어 학습과 디버깅이 쉬움
- **Python 기반 제어**: 초보자도 이해하기 쉬운 스크립트 언어
- **실시간 피드백**: LCD를 통해 현재 상태를 눈으로 확인 가능
- **재사용 가능한 코드**: Phase별 로직을 따로 저장하여 재활용
