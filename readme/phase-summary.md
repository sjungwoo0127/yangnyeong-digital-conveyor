# 단계별 요약

양녕 디지털고 컨베이어 시스템은 **5개의 Phase**로 구성됩니다.
각 Phase의 역할과 핵심 내용을 한눈에 볼 수 있도록 정리했습니다.

---

## 📋 5단계 전체 개요

| Phase | 이름 | 핵심 동작 | 상세 링크 |
|-------|------|-----------|-----------|
| **0** | 파라미터 설정 | 좌표/센서/초기화 값 세팅 | [바로 가기](../phase-0/README.md) |
| **1** | 홈 | 로봇을 기준 위치로 이동 | [바로 가기](../phase-1/README.md) |
| **2** | 컨베이어 이동 | 물체 집기 → 컨베이어 전달 | [바로 가기](../phase-2/README.md) |
| **3** | 스캔 준비 | 카메라 세팅 및 노출 조정 | [바로 가기](../phase-3/README.md) |
| **4** | 물체 분류 | AI 인식 후 분류 위치로 이동 | [바로 가기](../phase-4/README.md) |

---

## 🔢 Phase 0: 파라미터 설정

- 시스템이 기준으로 삼을 **좌표값과 초기 파라미터**를 입력합니다.
- 모든 이후 단계는 이 값을 참조합니다.

주요 파라미터:
- 집기 위치, 컨베이어 위치, 스캔 위치, 분류 위치, 홈 위치

---

## 🏠 Phase 1: 홈

- 로봇 팔을 **안전한 대기 위치(홈)**로 이동합니다.
- 매 사이클의 시작과 끝 지점입니다.

---

## 🤖 Phase 2: 컨베이어 이동

- 그리퍼로 물체를 **집고 들어 올린 뒤** 컨베이어 위에 놓습니다.
- 컨베이어 벨트가 물체를 스캔 위치까지 운반합니다.

---

## 📸 Phase 3: 스캔 준비

- **AI 카메라**의 노출, 게인, 레벨을 조정합니다.
- 물체를 안정적으로 인식할 수 있도록 조명 조건을 맞춥니다.

---

## 🎯 Phase 4: 물체 분류

- 카메라로 물체 종류를 인식합니다.
- **픽셀 좌표를 로봇 좌표로 변환**하여 지정된 분류 위치로 이동합니다.

---

## 🔄 전체 사이클 예시

```
홈 → 집기 → 들어올림 → 컨베이어 이동 → 내려놓기
  → 컨베이어 벨트 구동 → 스캔 위치 도착
  → AI 인식 → 좌표 변환 → 분류 위치로 이동 → 홈 복귀
```
