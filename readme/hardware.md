# 하드웨어 구성

## 🏗️ 전체 구성도

```
┌──────────────────────────────────────────────────┐
│  [로봇 팔]   [컨베이어 벨트]   [AI 카메라]         │
│      ↓              ↓               ↓            │
│   [그리퍼]    [모터 구동부]     [조명 모듈]        │
│      ↓              ↓               ↓            │
│  └───────── [제어 보드] ───────────┘              │
│                    ↓                              │
│                [LCD 화면]                          │
└──────────────────────────────────────────────────┘
```

---

## 🦾 로봇 팔

| 항목 | 사양 |
|------|------|
| **자유도** | 4축 (X, Y, Z, 회전) |
| **작업 반경** | 약 300mm |
| **제어 방식** | Python API를 통한 좌표 이동 |
| **홈 위치** | (280, 0) |

### 주요 API
```python
robot.move_to(x, y, z)   # 지정 좌표로 이동
robot.home()             # 홈 위치 복귀
```

---

## 🧲 그리퍼 (Gripper)

- **방식**: 공기 흡착 방식
- **제어**: ON/OFF 디지털 신호
- **압력**: 약 0.4 ~ 0.6 MPa

```python
robot.gripper_on()   # 흡착 시작
robot.gripper_off()  # 흡착 해제
```

---

## 🔁 컨베이어 벨트

| 항목 | 사양 |
|------|------|
| **길이** | 약 400mm |
| **속도 조절** | PWM 방식 |
| **방향** | 단방향 |

```python
conveyor.start(speed)
conveyor.stop()
```

---

## 📷 AI 카메라

- **해상도**: 640 x 480
- **인식 방식**: 사전 학습된 AI 모델 기반 객체 분류
- **조명**: 별도 LED 링 라이트 사용

```python
cam.ai_init(model_id)       # AI 모델 로드
result = cam.ai_detect()    # 객체 인식
```

---

## 🖥️ LCD 디스플레이

- **용도**: 현재 Phase, 인식 결과, 에러 메시지 표시
- **인터페이스**: I2C

```python
lcd.print("Phase 2: 컨베이어 이동")
```
