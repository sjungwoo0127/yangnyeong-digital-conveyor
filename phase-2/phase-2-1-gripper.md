# 물체 집기 (Gripper Control)

## ✋ 개요

로봇의 흡입 기능을 사용하여 물체를 집습니다.

---

## 🔄 동작 과정

### 1단계: 집기 위치로 이동 (상단)

```python
집기_Y = 집기_y_좌표__목록[i]  # i번째 물체 Y좌표 선택
robot.moveG0(집기_x__좌표, 집기_Y, 기본_Z__좌표)
```

**결과**: 로봇이 안전 높이(Z=100)에서 집기 위치로 이동

---

### 2단계: 내려가기

```python
robot.moveG0(집기_x__좌표, 집기_Y, 집기_z__좌표)
```

**결과**: 로봇이 물체 위치(Z=-60)까지 내려감

---

### 3단계: 흡입 시작

```python
robot.suctionOn()   # 흡입 시작
time.sleep(1)       # 1초 대기 (안정화)
```

**결과**: 흡입기가 켜져 물체를 집음

---

### 4단계: 들어올리기

```python
robot.moveG0(집기_x__좌표, 집기_Y, 기본_Z__좌표)
```

**결과**: 물체를 든 상태로 안전 높이까지 올림

---

## ⚙️ 파라미터 조정

| 파라미터 | 현재값 | 설명 | 조정 |
|---------|-------|------|------|
| `집기_z__좌표` | -60 | 내려가는 깊이 | 더 깊이: -80 / 덜 깊이: -40 |
| `sleep(1)` | 1초 | 흡입 유지 시간 | 무거운 물체: 2초 / 가벼운 물체: 0.5초 |

---

## 💡 팁

- **물체가 안 집혀질 때**: 깊이(`집기_z__좌표`) 또는 대기시간 증가
- **물체가 쓸려갈 때**: 깊이를 덜 내려가기 (`-60` → `-50`)
