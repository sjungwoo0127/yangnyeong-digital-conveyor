# 양녕 디지털고 컨베이어 운영 메뉴얼

이 메뉴얼은 컨베이어 로봇 시스템의 운영 및 제어 방법을 설명합니다.  
복잡한 기계를 누구나 쉽게 이해하고 운영할 수 있도록 단계별로 정리했습니다.

## 🎯 주요 기능

- **물체 집기**: 지정된 위치에서 물체를 자동으로 집음
- **컨베이어 이동**: 집은 물체를 컨베이어로 전달
- **이미지 스캔**: AI 카메라로 물체 인식
- **자동 분류**: 인식된 물체 종류별로 분류

## 📋 5가지 운영 단계

1. **Phase 0** - 파라미터 설정: 시스템 초기화 및 설정값 입력
2. **Phase 1** - 홈: 로봇을 대기 위치로 이동
3. **Phase 2** - 컨베이어 이동: 물체를 집어 컨베이어로 옮기기
4. **Phase 3** - 스캔: 물체를 카메라로 인식하기
5. **Phase 4** - 분류: 인식 결과에 따라 분류 위치로 이동

각 단계는 자동으로 진행되며, 필요한 코드와 파라미터는 각 섹션에서 확인할 수 있습니다.
