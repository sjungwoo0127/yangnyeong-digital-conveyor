# 초기화 과정

## 블록 다이어그램

![초기화 블록 흐름](../assets/phase-0-3-initialization.png)

> 블록 이미지 공간 - 사용자가 나중에 삽입

---

## 개요

시스템을 켜면 제일 먼저 실행되는 "한 번만 돌리는 블록들" 모음입니다.
이 블록들을 순서대로 실행해야 Phase 1~4 가 제대로 동작합니다.

---

## 블록별 설명

### 블록 1️⃣: 라이브러리 불러오기 블록

**기능**: 로봇/카메라/LCD/버튼 등 장치를 사용하기 위한 모듈 불러오기
- 블록 코딩에서는 "프로그램 시작 시 실행" 블록 아래에 자동 포함
- 각 장치 블록을 사용하려면 이 블록이 먼저 실행되어야 함

**불러오는 장치**:
- 로봇 제어 블록
- 시간 지연(sleep) 블록
- 버튼 입력 블록
- 카메라 센서 블록
- AI 카메라 블록
- LCD 출력 블록
- 수학 함수 블록

---

### 블록 2️⃣: 하드웨어 초기화 블록

**기능**: LCD 화면을 켜고 AI 카메라를 시작
- "LCD 시작" + "AI 카메라 시작" 2개 블록 묶음

**파라미터**:
- AI 추적 물체 수: 5개

**주의사항**:
- LCD가 켜지지 않으면 화면이 까맣게 보임
- AI 초기화에는 약 1~2초 소요

---

### 블록 3️⃣: 파라미터 정의 블록 모음

**기능**: Phase 0-1에서 정의한 모든 좌표값을 변수에 저장
- 집기 Y 좌표 목록, 집기 X 좌표, 집기 Z 좌표 등

**파라미터**:
- Phase 0-1 [파라미터 상세 가이드](phase-0-1-parameter-guide.md) 참고

---

### 블록 4️⃣: 시작 대기 루프 블록

**기능**: 버튼을 누를 때까지 홈에서 대기
- "계속 반복하기" 블록 안에 "홈으로 이동" + "버튼 입력 확인" 배치
- 버튼을 누르면 루프를 빠져나와 Phase 2 시작

**동작 순서**:
1. 짧은 대기 (CPU 과부하 방지)
2. 로봇을 홈 위치로 이동
3. 버튼 입력 확인
4. 눌렸으면 → Phase 2 로 진행
5. 안 눌렸으면 → 1번으로 반복

**파라미터**:
- 대기 시간: 0.000001초 (거의 즉시)
- 홈 위치: (280, 0, 0)
