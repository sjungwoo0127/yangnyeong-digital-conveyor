# 파라미터 상세 가이드

## 📍 각 파라미터 설정

### 집기 위치 (Pick Position)

```python
집기_x__좌표 = 277              # 집기 X축 위치 (고정)
집기_y_좌표__목록 = [-40, 0, 40]  # 3개 물체의 Y축 위치
집기_z__좌표 = -60             # 물체를 집는 깊이 (내려가는 정도)
집기__높이 = 22                # 물체 흡입 높이
```

**조정 방법**:

* 더 깊이 집으려면: `집기_z__좌표` 음수 증가 (예: -60 → -80)
* 물체가 3개 이상: `집기_y_좌표__목록` 항목 추가

***

### 컨베이어 위치 (Conveyor Position)

```python
컨베이어__대기 = (230, 250, 80)    # 컨베이어 대기 위치
컨베이어__놓기 = (230, 260, 22)    # 물체 놓는 위치
```

***

### 홈 위치 (Home Position)

```python
HOME_X__좌표 = 280  # X축 홈 위치
HOME_Y__좌표 = 0    # Y축 홈 위치
HOME = (280, 0, 0)  # 홈 좌표
```

***

### 분류 위치 (Classification Position)

```python
분류_x__좌표 = -270              # 분류 X축 위치 (고정)
분류_y_좌표__목록 = [80, 5, -70]   # 3개 분류 위치 Y축
분류_z__좌표 = 0                # 분류 Z축 (물체 놓기 깊이)
```

**물체 분류 규칙**:

* tag\_id = 1 → Y = 80
* tag\_id = 2 → Y = 5
* tag\_id = 3 → Y = -70
