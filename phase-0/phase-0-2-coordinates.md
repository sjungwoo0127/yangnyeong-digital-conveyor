## 좌표 시스템 개요

로봇은 3D 공간에서 움직입니다.

```
        Z축 (높이)
          ↑
          |
Y축 (앞뒤) | 집기 위치 (277, -40~40, -60)
↗        |     
         +------→ X축 (좌우)
```

- **X축**: 좌우 이동
- **Y축**: 앞뒤 이동
- **Z축**: 위아래 이동 (높이)

---

## 블록별 설명

### 블록 1️⃣: 위치별 좌표 정의 블록

**기능**: 각 작업 위치의 (X, Y, Z) 값을 저장
- 블록 코딩에서는 각 위치를 "좌표 세트" 블록으로 묶어 표현

**파라미터**:

| 위치 | X | Y | Z | 설명 |
|------|----|----|----|----|
| 홈 (HOME) | 280 | 0 | 0 | 대기 위치 |
| 집기 | 277 | -40, 0, 40 | -60 | 물체 집기 위치 |
| 컨베이어 | 230 | 250 | 80 | 컨베이어 대기 |
| 스캔 | 0 | 230 | 100 | 카메라 인식 |
| 분류 | -270 | 80, 5, -70 | 0 | 물체 분류 |

---

### 블록 2️⃣: Y축 좌표 목록 확장 블록

**기능**: 물체 개수가 늘어나면 Y 좌표 목록에 값을 추가
- "목록에 값 추가" 블록 사용

**파라미터**:
- 기존 Y 목록: [-40, 0, 40]
- 4개로 확장 시: [-40, 0, 40, 80]

**주의사항**:
- 목록 개수와 실제 물체 개수가 일치해야 함

---

### 블록 3️⃣: Z축(높이) 조정 블록

**기능**: 물체 크기에 맞게 Z축 내려가는 깊이 조정
- 물체가 크면 덜 내려감 (Z 값 증가)
- 물체가 작으면 더 내려감 (Z 값 감소)

**파라미터 예시**:
- 기본 깊이: Z = -60
- 큰 물체: Z = -50 (덜 내려감)
- 작은 물체: Z = -80 (더 내려감)

---

### 블록 4️⃣: 안전 높이 블록

**기능**: 수평 이동 시 반드시 유지해야 할 최소 높이
- 로봇이 다른 장비와 충돌하지 않도록 하는 "이동 전용 높이"

**파라미터**:
- 기본 Z(안전 높이): 100

**주의사항**:
- 이 값 미만에서는 수평 이동 금지
- 수평 이동 전에는 반드시 이 높이까지 올라가야 함
