# Phase 0: 파라미터 설정

## 블록 다이어그램

> 블록 이미지 공간 - 사용자가 나중에 삽입

***

## 개요

시스템을 시작하기 전에 로봇이 움직일 위치(좌표)와 각 센서를 설정합니다. 블록 코딩에서는 "값 설정" 블록들을 순서대로 조립해 로봇에게 "어디로 갈 수 있는지"를 알려주는 단계입니다.

***

## 블록별 설명

### 블록 1️⃣: 좌표값 설정 블록

**기능**: 로봇이 이동할 각 위치의 좌표값을 변수에 저장

* "값 설정" 블록을 여러 개 이어 붙여 좌표를 정의
* 집기 위치, 컨베이어 위치, 스캔 위치, 분류 위치, 홈 위치를 한 번에 지정
* 값을 바꾸면 그 다음 Phase 전체 동작이 자동으로 바뀜

**파라미터**:

* 집기 위치 X: 277 (고정)
* 집기 위치 Y: -40, 0, 40 (3개 중 선택)
* 컨베이어 위치: (230, 250)
* 스캔 위치: (0, 230)
* 분류 위치 X: -270 (고정)
* 분류 위치 Y: 80, 5, -70 (3개 중 선택)
* 홈 위치: (280, 0)

**주의사항**:

* 좌표값을 잘못 입력하면 로봇이 엉뚱한 곳으로 이동할 수 있음
* 물체의 크기/개수가 바뀌면 Y 좌표 목록도 수정 필요

***

### 블록 2️⃣: LCD 화면 초기화 블록

**기능**: LCD 화면을 켜서 상태를 표시할 준비

* 메뉴얼 시작 시 한 번만 실행
* 진행 상황을 화면에 보여줌

**파라미터**: 없음

***

### 블록 3️⃣: 카메라 AI 초기화 블록

**기능**: AI 카메라를 물체 인식 모드로 시작

* 한 화면에서 감지할 수 있는 최대 물체 개수를 지정
* 시스템이 켜질 때 딱 한 번 실행

**파라미터**:

* 최대 추적 물체 수: 5개

**주의사항**:

* AI 초기화는 몇 초 걸릴 수 있음
* 초기화 중에는 로봇을 움직이지 말 것
