# 홈 위치 (Home Position Details)

## 🏠 개요

홈은 모든 작업 사이클의 시작점이자 로봇의 안전한 대기 위치입니다.

---

## 📍 홈 좌표

```python
HOME_X__좌표 = 280
HOME_Y__좌표 = 0
HOME = (280, 0, 0)
```

**안전 높이**: 로봇이 항상 Z ≥ 100 에서 이동하므로 안전

---

## 🎯 홈의 역할

1. **시작 위치**: 모든 사이클이 여기서 시작
2. **대기 위치**: 버튼 입력 대기 중
3. **안전 위치**: 다른 장비와 충돌 없음
4. **기준점**: 좌표 계산의 기준

---

## 🔄 홈으로 돌아가기

```python
# 어느 위치에서든 홈으로 복귀
robot.moveG0(HOME_X__좌표, HOME_Y__좌표, 기본_Z__좌표)
```

---

## ⚙️ 홈 위치 변경

만약 다른 위치가 더 안전하면:

```python
HOME_X__좌표 = 300  # 변경
HOME_Y__좌표 = 20   # 변경
```

> **주의**: 변경 후 로봇이 집기 위치, 컨베이어, 분류 위치와 충돌하지 않는지 확인
