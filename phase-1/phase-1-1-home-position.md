# 홈 위치 상세

## 블록 다이어그램

> 블록 이미지 공간 - 사용자가 나중에 삽입

***

## 개요

홈은 모든 작업 사이클의 시작점이자 로봇의 안전한 대기 위치입니다.

***

## 블록별 설명

### 블록 1️⃣: 홈 좌표 정의 블록

**기능**: 홈 위치의 X, Y, Z 좌표를 변수로 저장

* Phase 0에서 정의한 값을 여기서 재사용
* 홈 좌표를 바꾸고 싶다면 이 블록의 값을 수정

**파라미터**:

* HOME X: 280
* HOME Y: 0
* HOME Z: 0 (참고용 기본값, 실제 이동 시에는 안전 높이 사용)
* HOME 좌표: (280, 0, 0)

**안전 기준**:

* 이동 시에는 항상 Z ≥ 100 에서 움직이도록 설계되어 있음

***

### 블록 2️⃣: 홈으로 복귀 블록

**기능**: 현재 어디에 있든 홈 위치로 즉시 이동

* "로봇 이동" 블록에 홈 X/Y + 안전 높이 Z 연결
* 사이클 종료 시, 에러 시 언제든 호출 가능

**파라미터**:

* X: HOME X (280)
* Y: HOME Y (0)
* Z: 기본 Z (100, 안전 높이)

***

### 블록 3️⃣: 홈 위치 변경 블록 (선택)

**기능**: 홈 위치를 다른 곳으로 바꿀 때 사용

* 작업대 배치가 바뀌면 값만 수정하여 전체 동작을 재배치

**파라미터 예시**:

* 기본: X=280, Y=0
* 변경 예: X=300, Y=20

**주의사항**:

* 변경 후 집기/컨베이어/스캔/분류 위치와 충돌하지 않는지 실제 이동으로 확인
* 홈을 작업 영역 안쪽으로 너무 옮기면 다른 장비와 부딪힐 수 있음

***

## 홈의 역할 요약

1. **시작 위치**: 모든 사이클이 여기서 시작
2. **대기 위치**: 버튼 입력을 기다리는 위치
3. **안전 위치**: 다른 장비와 충돌 없음
4. **기준점**: 다른 좌표 계산의 기준
