# 로봇 이동 방식 (Robot Movement)

## 블록 다이어그램

![로봇 이동 블록](../assets/phase-1-2-movement.png)

> 블록 이미지 공간 - 사용자가 나중에 삽입

---

## 개요

로봇이 한 위치에서 다른 위치로 이동하는 "이동 블록"의 사용 방법을 설명합니다.

---

## 블록별 설명

### 블록 1️⃣: 로봇 이동 블록

**기능**: 지정한 (X, Y, Z) 좌표로 로봇을 빠르게 이동
- 블록 코딩에서 가장 많이 쓰이는 핵심 블록
- 직선 경로로 최대 속도로 이동

**파라미터**:
- X: 좌우 좌표 (mm)
- Y: 앞뒤 좌표 (mm)
- Z: 높이 좌표 (mm)

**이동 특성**:
- 속도: 빠름 (rapid movement)
- 경로: 직선
- 안전성: 반드시 안전 높이에서 수평 이동

---

### 블록 2️⃣: 안전 높이 올리기 블록

**기능**: 현재 위치에서 Z만 안전 높이(100)로 올림
- 수평 이동 전에 반드시 사용
- 다른 장비와의 충돌 방지

**파라미터**:
- X: 현재 X (그대로)
- Y: 현재 Y (그대로)
- Z: 100 (안전 높이)

**사용 순서 예시**:
1. 블록 2️⃣: 안전 높이로 올라가기
2. 블록 1️⃣: 목표 X, Y로 이동 (Z=100 유지)
3. 블록 3️⃣: 작업 높이로 내려가기

---

### 블록 3️⃣: 작업 높이로 내려가기 블록

**기능**: 목표 위치 도착 후 실제 작업 높이까지 내려감
- 집기/놓기 작업 전에 사용
- X, Y는 그대로 두고 Z만 변경

**파라미터 예시**:
- 컨베이어 놓기: Z = 22
- 집기: Z = -60

---

### 블록 4️⃣: 이동 후 안정화 대기 블록

**기능**: 이동 후 로봇이 떨리지 않도록 잠시 기다림
- "기다리기" 블록을 이동 뒤에 붙임

**파라미터**:
- 기본 대기 시간: 0.5초
- 긴 이동 후: 1초
- 흡입 직후: 1~2초

---

## 안전한 이동 패턴

### 패턴 A: 높이 먼저 올리고 수평 이동

1. 현재 낮은 위치에 있음 (예: Z=-60)
2. 블록 2️⃣: Z만 100으로 올리기
3. 블록 1️⃣: 목표 X/Y로 이동 (Z=100 유지)

→ 충돌 없이 안전하게 수평 이동 완료

---

### 패턴 B: 도착 후 내려가기

1. 안전 높이(Z=100)에서 목표 X/Y 도착
2. 블록 3️⃣: Z만 작업 높이로 내려가기

→ 작업 직전 단계

---

## 팁

- 수평 이동 시 **Z ≥ 100** 유지는 가장 중요한 안전 규칙
- 목표 도착 후에만 Z를 내려라
- 이동 후에는 안정화 대기 블록을 꼭 넣어 떨림 방지
