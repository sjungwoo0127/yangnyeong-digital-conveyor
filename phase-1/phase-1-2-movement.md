# 로봇 이동 방식 (Robot Movement)

## 🤖 개요

로봇이 한 위치에서 다른 위치로 이동하는 방식을 설명합니다.

---

## 🖥️ 이동 명령

```python
# 목표 위치로 이동
robot.moveG0(x, y, z)
```

**매개변수**:
- `x`: X축 좌표 (mm)
- `y`: Y축 좌표 (mm)
- `z`: Z축 높이 (mm)

---

## 📊 이동 특성

| 특성 | 설명 |
|------|------|
| **속도** | 빠름 (G0 = rapid movement) |
| **경로** | 직선 이동 |
| **안전성** | 높은 높이에서만 이동 |

---

## 🔄 안전한 이동 패턴

### 패턴 1: 높이를 먼저 올리기

```python
# 현재 위치: (277, -40, -60) ← 낮음

# Step 1: 안전 높이로 올리기
robot.moveG0(277, -40, 100)  # Z만 변경

# Step 2: 수평 이동
robot.moveG0(230, 250, 100)  # X, Y 변경
```

**이유**: 충돌 방지

---

### 패턴 2: 도착 후 내려가기

```python
# 도착 위치: (230, 250)

# Step 1: 안전 높이에서 도착
robot.moveG0(230, 250, 100)

# Step 2: 작업 위치로 내려가기
robot.moveG0(230, 250, 22)  # Z만 변경
```

---

## ⚙️ 이동 속도 조절

기본 `moveG0`는 최대 속도입니다.

더 느리게 이동하려면:
```python
time.sleep(0.5)  # 이동 후 안정화 시간
```

---

## 💡 팁

- 항상 **높이 ≥ 100** 에서 수평 이동
- 목표 위치에 도착 후 작은 높이로 조정
- 이동 후 `time.sleep()` 으로 안정화
