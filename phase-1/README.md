## 블록별 설명

### 블록 1️⃣: 홈으로 이동 블록

**기능**: 로봇을 홈 좌표로 빠르게 이동

* "로봇 이동" 블록에 홈 좌표값을 연결
* Phase 1은 사실상 이 블록 하나로 이루어짐

**파라미터**:

* X: 280 (HOME X 좌표)
* Y: 0 (HOME Y 좌표)
* Z: 100 (기본/안전 높이)

**주의사항**:

* 반드시 안전 높이(Z=100)를 사용해야 다른 위치와 충돌하지 않음
* 이동이 끝나면 다음 단계(Phase 2)가 시작됨
